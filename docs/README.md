# docs

Nơi để báo cáo, sơ đồ, slide và bằng chứng.

| Đường dẫn | Nội dung | Người phụ trách |
| --- | --- | --- |
| `seed-data.md` | Dữ liệu mẫu dùng cho test | Quý |
| `evidence/` | Ảnh chụp và video chứng minh hệ thống chạy được | Quý |
| `meetings/` | Biên bản họp nhóm, mỗi buổi một file | Nhật Tiến |
| sơ đồ kiến trúc (`.drawio` và `.png`) | Mục B | Quốc Tiến |
| sơ đồ luồng dữ liệu của 3 nghiệp vụ | Mục A | Tuấn |
| báo cáo và slide | Bản ghép cuối | Nhật Tiến |

Quy ước đặt tên ảnh trong `evidence/`: chữ cái của mục báo cáo, số thứ tự, mô tả ngắn. Ví dụ `C-01-docker.png`, `C-10-search-loc-category.png`.
